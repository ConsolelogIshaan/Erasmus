## Tunnel launcher
`Start-Lisbon-Tunnel.bat` is a root-level double-click launcher. It starts the existing `ErasmusRelay` scheduled task if stopped, otherwise relies on the running supervisor self-healing a dead tunnel; if the task is missing, it starts the existing daemon. It waits up to two minutes for the Cloudflare relay Worker `/status` to report a healthy tunnel and relay. The file was not executed during creation, so the active tunnel and running task were left undisturbed.
