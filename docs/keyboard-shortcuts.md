# Keyboard shortcuts

Frame is keyboard-first. Shortcuts work on authenticated pages (outside text fields, except ⌘K).

| Keys | Action |
| --- | --- |
| `⌘K` / `Ctrl+K` | Open Search page |
| `/` | Open search |
| `G` then `D` | Home dashboard |
| `G` then `L` | Library |
| `G` then `C` | Collections |
| `G` then `X` | Discover |
| `G` then `A` | Anime |
| `G` then `W` | Watchlist |
| `G` then `P` | Profile (Dashboard) |
| `G` then `,` | Settings |
| `Esc` | Close modals (browser default + Radix) |
| `Enter` | Submit search |

Source of truth: `src/constants/shortcuts.ts`  
Also listed under **Settings → Keyboard**.
